# JA2 Stracciatella Item Database

A single-page web application for browsing **Jagged Alliance 2 Stracciatella** item data.

Currently focuses on **Armor**. Designed to be easily expandable with Guns and Accessories.

## Features

- Dark military / tactical JA2-inspired design
- Filter by armor class (Helmet, Vest, Leggings)
- Live search
- Detailed modal view
- Data extracted from the official `armours.json`
- Pure HTML/CSS/JS – no build step required

## Live Preview

Enable **GitHub Pages** on this repository (Settings → Pages → Deploy from branch `main` / root) to view it live at:

`https://khkrol.github.io/ja2-stracciatella-database/`

## Data

Armor data is in `data/armors.json` (cleaned and structured from the official Stracciatella sources).
